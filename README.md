## Estructura del Proyecto
```text
Proyecto_Ingenieria_Software/
│
├── index.html          # Página principal con Login, Registro y acceso a las 4 unidades
├── unidad1.html        # Unidad I: Fundamentos de la Ingeniería de Software y del Proceso
├── unidad2.html        # Unidad II: Análisis y Modelado de Requisitos
├── unidad3.html        # Unidad III: Gestión, Planificación y Calidad de Proyectos
├── unidad4.html        # Unidad IV: Diseño y Pruebas del Software
│
├── css/
│   └── estilos.css     # Hoja de estilos CSS
│
├── js/
│   ├── funciones.js     # Validación de Login/Registro, base de datos simulada y navegación
│   ├── cuestionarios.js # Cuestionarios calificables de las 4 unidades con retroalimentación
│
├── data/
│   ├── usuario.json    # Base de datos simulada en formato JSON
│   └── usuario.txt     # Registro de usuarios en formato TXT
│
├── videos/
│   └── recursos_audiovisuales.txt # Índice de videos explicativos con sus fuentes
│
├── imagenes/
│   ├── diagrama_unidad1.svg
│   ├── diagrama_unidad2.svg
│   ├── diagrama_unidad3.svg
│   └── diagrama_unidad4.svg

└── README.md
```
